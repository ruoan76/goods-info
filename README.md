# goods-info

商品主数据治理与管理系统项目。

## 目录

- `apps/` 应用源码
- `governance/` 治理规则、执行脚本和批次工具
- `db/` 数据库结构、迁移和维护 SQL
- `docs/` 当前方案、评审、实施文档和历史归档
- `ops/` 部署、备份和运维检查
- `data/` 运行数据、临时文件和归档数据
- `reports/` 当前报告与执行证据
- `vendor/` 离线依赖包

`08_治理执行` 保留为兼容入口。管理系统的代码、文档和运行数据使用上述目录。

正式数据源为 PostgreSQL `goods_mdm`。SQLite 文件仅作为历史归档或受控演练输入。
