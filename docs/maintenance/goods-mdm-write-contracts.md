# 商品写入与导出契约（2026-11-27）

本文覆盖历史设计文档中不一致的表述；历史资料保留在 `docs/archive/`。

## 换码

Steward 的 `/api/v1/barcodes/reassign` 在同一事务内检查原码、新码、ISBN、别名和禁复用记录。新码也不能关联遗留属性或历史，避免把不同身份的数据混在一起；作废商品不能换码。事务显式更新商品主键、属性条码、历史条码及所有别名的主条码，新增原码的 90 天禁用记录（指向新主码）、换码历史与审计。任何失败均回滚；原始审计的 entity_key/before_data/after_data 保持不可变，通过换码事件关联。

现网目录确认没有指向 `mdm_goods` 的外键，不能依赖 CASCADE。换码是少量管理操作，使用短事务内的表级写互斥锁保护跨表迁移；普通查询仍可运行，其他写入可能短暂等待。锁等待上限 5 秒，超时整体失败；大历史量商品应在低峰换码。建档和别名写入在准入读取前获取兼容写锁，避免等待换码后使用过期的校验结果。生产没有执行任何换码。

## 分类

建档、CSV 导入、改类共用 DAO 分类校验：分类存在、启用、为末级，父链完整、无环且启用。代码路径由父链生成，不信任可能已过期的目录物化路径；商品 `category_path` 随写入同步。

有分类的新商品与人工改类记录 `category_source=MANUAL`；未提供分类或显式选择 C00 的商品为 `UNCLASSIFIED`。改类清空旧 `category_confidence`，保留原 `governance_batch`、`decision_trace` 和其他字段的来源信息，它们是原始治理血缘；当前分类变更以历史及审计为准。未变更商品不批量覆盖来源字段。

列表和详情的 `category_path` 返回完整中文路径，如 `食品 / 饮料 / 茶饮`；`category_code_path` 保留商品存储的编码路径，如 `/C01/C0101/C010101/`。目录按请求一次读取，支持多级树，不按商品查询。历史数据父链缺失或成环时中文路径返回 null，编码字段照原值返回，避免伪造完整路径。历史商品冗余路径修复另见 `db/maintenance/goods-mdm/repair_category_paths.sql`；脚本仅针对显式指定条码，默认只预览并回滚；尚未在生产执行。

## ISBN、批次与认证

现行新建准入契约仍拒绝 978/979 前缀（业务码 3004）；单条建档、CSV 导入及 validate 使用相同策略，换码目标也适用。`r16_fix.sql` 将既有 ISBN 记录归类，是历史数据治理，不表示开放新品 ISBN 准入；没有删除或变更既有图书数据。

人工批次号保留 `MAN-时间-操作人` 可读前缀，追加完整 UUID，避免同秒同操作人导入冲突。只生成一次并在整批复用，一批可有多条历史和审计。现网 `sys_import_job/sys_change_log/sys_gov_batch/mdm_goods_history` 的 batch_id 及商品 governance_batch 均为 text，无长度上限；没有为 `sys_change_log.batch_id` 加唯一约束。

认证对账户行加锁后读取失败次数、锁定状态并验证密码；失败计数提交后返回 401，成功重置亦在同一行锁内提交。达到 5 次失败锁定 10 分钟，锁定时正确密码也不能绕过。

## CSV 导出

商品和治理清单导出都按筛选条件最多输出 **200000 条数据行**，不受当前列表页码影响，**并非无限制全量导出**。使用数据库服务端游标，每次最多取 2000 行，HTTP 使用 StreamingResponse。额外最多读取 1 行检测截断；超限时文件末尾增加以 `#` 开始的提示行，提示缩小筛选范围，提示行不算商品数据行。响应头 `X-Export-Limit: 200000` 声明上限；原 BOM、CSV 字段、文件名和角色权限保留。

商品导出启动前写入审计，结束或中断记录已生成行数、完成状态及截断状态，同一批次关联。治理清单继续使用只读数据库账户。正常结束、客户端断开、发送失败或数据库错误时都关闭游标、结束事务并归还连接；请求尚未开始迭代时不持有导出连接。浏览器当前仍用 blob 下载，本次解决的是服务端数据库与 HTTP 流式输出。
